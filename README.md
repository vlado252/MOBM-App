# MOBM_App

Учебное WPF-приложение на C# для работы
с производственными данными и заказами.

## Технологии
- C#
- WPF и XAML
- Visual Studio

## Структура проекта
- Models — модели данных
- Views — пользовательский интерфейс
- ViewModels — логика взаимодействия интерфейса
- Services — сервисные классы
- Helpers — вспомогательные классы

## Возможности проекта
- Интерфейс авторизации и регистрации
- Работа с заказами и производственными данными
- Организация работы с данными
- Формирование PDF-документов

## Запуск
Откройте файл MOBM_App.sln в Visual Studio,
соберите проект и запустите приложение.
